# number-guessing-game

Консольная мини-игра на Python. Компьютер загадывает число от 1 до 100 — игрок отгадывает за ограниченное число попыток, получая подсказки о направлении.

## Возможности

- 🎮 Ограничение числа попыток (12 по умолчанию)
- 🛡️ Защита от некорректного ввода — буквы и пустые строки не ломают игру
- 📊 Подсчёт побед и поражений за сессию
- 🔁 Повтор игры без перезапуска программы

## Запуск

```bash
python guess_number.py
```

## Пример работы

```
========================================
           ИГРА «УГАДАЙ ЧИСЛО»
========================================

Я загадала число от 1 до 100.
Попыток осталось: 12

Попытка 1: 50
Загаданное число меньше. Осталось попыток: 11

Попытка 2: 25
Загаданное число больше. Осталось попыток: 10

Попытка 3: 37

Верно! Число было 37.
Вы угадали за 3 попыток.

Счёт — побед: 1, поражений: 0
```

## Стек

- Python 3.10+
- Стандартная библиотека (без внешних зависимостей)
